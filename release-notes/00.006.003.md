## Fixes
- In-app updates now install correctly. Before, the updated app wouldn't start ("Can't start the game or app", CE-107750-0): the updater wrote the new files without execute permission.
- The update is unpacked next to the app, the app closes, and a background helper installs it. A notification says when to open the app again.

## If you have 0.6.0, 0.6.1 or 0.6.2
- Install this version by hand once: delete /data/homebrew/PPSA99064, then copy the PPSA99064 folder from Mupen64PlusPS5.zip to /data/homebrew/.
- Those versions don't offer this update themselves (their updater would break the app). Updates after this one install from inside the app.
