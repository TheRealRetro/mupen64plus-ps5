## New
- GPU renderer (paraLLEl-RDP on Vulkan), on by default: games are drawn at 4x the N64's resolution (1x-8x in Settings, Internal resolution). GoldenEye 007, Perfect Dark, Conker, Majora's Mask and Donkey Kong 64 run at full speed.
- Faster sound processing (HLE), on by default. If a game's sound is wrong, set Audio processing to Accurate (LLE).
- Settings: Renderer (GPU or CPU), Internal resolution, GPU sync, Audio processing.

## Fixes
- When a game blanks the screen while loading (Perfect Dark), the screen now goes black instead of showing the last picture, which looked like a freeze.
- The pause menu scrolls: it no longer runs off the bottom of the screen.
- The logs folder keeps the last 5 sessions (boot.log, boot.prev.log to boot.prev4.log).

## Good to know
- The first time a new scene appears, the GPU may pause briefly while it prepares that scene's shaders. They are saved, so it won't pause there again.
